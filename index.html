重庆 3 天游玩路书

鱼复 / 南山住宿版 · 步行与轨道交通优先 · 点击地点即可跳转高德定位

住宿：两江鱼复智选假日酒店（Day 1–2）｜南山宾馆（Day 3）。高德路线链接一次最多支持一个途经点，因此按分段导航更稳定。

Day 1｜鱼复出发 · 渝中老城 · 洪崖洞夜景

07:20 从酒店出发。鱼嘴站→4号线→民安大道换乘3号线→两路口换乘1号线，七星岗/较场口下车；预留 80–100 分钟。夜间从小什字/较场口原路回鱼嘴。

09:00
山城步道（山城巷入口）
古城墙、老居民区与崖边步道，预留 1.5–2 小时。
高德定位
11:15
十八梯传统风貌区
从上往下逛更省体力；午餐不宜排队太久。
高德定位
14:00–20:30
解放碑 → 戴家巷 → 洪崖洞 → 千厮门大桥
午餐可定位九宫格火锅（洪崖洞店）；傍晚先逛洪崖洞，点灯后上千厮门大桥拍夜景。
洪崖洞高德定位

Day 2｜动物园 · 李子坝 · 北城夜景

07:00 从鱼复出发，按高德实时公交从鱼嘴站前往动物园，预留约 90 分钟。晚间鸿恩寺打车至观音桥/红旗河沟后再回鱼嘴。

08:30
重庆动物园
开园即进看大熊猫，预留 2–3 小时，节假日提前预约。
高德定位
12:00–15:30
鹅岭公园 → 鹅岭二厂 → 李子坝观景平台
鹅岭登高，二厂拍照咖啡，李子坝等1–2趟轻轨即可。
李子坝高德定位
16:00–21:30
北仓文创街区 → 观音桥大屏 → 鸿恩寺森林公园
晚餐可定位李串串老店·李杰一家三口（观音桥）；鸿恩寺看夜景后尽早返程。
鸿恩寺高德定位

Day 3｜换住南山 · 两江小渡 · 南岸老街

上午从鱼复退房后，将行李直接送至南山宾馆寄存/办理入住；不要拖箱坐渡轮或爬老街台阶。结束后由南滨路打车上南山宾馆。
08:40
洪崖洞码头 · 两江小渡
提前20分钟到码头，乘洪崖洞—弹子石方向；航次以当天通知为准。
高德定位
09:30–17:30
弹子石老街 → 龙门浩老街 → 下浩里 → 南滨路
午餐按高德定位曼妙爬爬虾家常海鲜；由弹子石沿南滨路向西，傍晚在江边看两江夜景。
弹子石高德定位

出发前检查

  • 动物园门票、两江小渡航次当天早上再确认。
  • 高德开启“避开拥堵”；跨区优先实时轨道交通方案。
  • 山城步道、十八梯、龙门浩、下浩里台阶多：轻装、防滑鞋、雨具和充电宝必带。
  • 国庆餐饮以“近、可排号、已营业”为优先。
